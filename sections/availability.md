## 8 Data and code

The pipeline is Desk Studio, an open-source design studio for coding agents, at https://github.com/adityareddy-dev/deskstudio under the MIT licence. The `--no-proof` flag used for the off arm is a small change to `runner/run.mjs` on the branch `study/no-proof` of that repository. The study record holds, for each of the 60 jobs, the manifest, the run log, the hidden audit, the offline recheck of every round, the brief, the full state file with every sign-off's scores and notes, the signed-off `final.html` and the handback, together with the case file, the batch runner, the recheck and analysis scripts, the two readers' codes for all 754 notes with the adjudicated final code, the figures, and the preregistered design note with its dated change. The 2,000 round renders, about 95 MB, go with the deposited record. The three nano-builder jobs set aside before analysis are in the record under their own folder.
